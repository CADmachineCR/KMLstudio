# 🌍 KML Studio

![License](https://img.shields.io/badge/License-Proprietary-red)

**KML Studio** is a lightning-fast, client-side web application designed to generate, compress, and preview Keyhole Markup Language (KML) and KMZ files directly in the browser. 

It solves a common problem for mobile users, topographers, and architects: smartphone text editors often corrupt geographic coordinate codes by saving them as `.txt`. This tool forces the browser to save the exact `.kml` or `.kmz` format, ready to be imported into Google Earth.

## ✨ Key Features

*   🗺️ **Interactive Map Preview:** Render and verify your KML coordinates instantly using Leaflet.js.
*   📦 **On-the-fly KMZ Compression:** Compress bulky KML files into `.kmz` (zipped) format in milliseconds using JSZip.
*   🔒 **100% Client-Side (Privacy First):** No databases, no external servers. All data processing happens securely within the user's local browser.
*   🌐 **Multilingual Support:** Auto-detects and supports 7 languages: English, Spanish, Portuguese, French, German, Chinese, and Japanese.
*   📱 **Responsive Design:** Fully optimized for both desktop and mobile use.
