What is a KML / KMZ file?

A KML (Keyhole Markup Language) file is a format used to display geographic data in an Earth browser such as Google Earth. It allows you to draw points, lines, and polygons to map out routes or land boundaries. A KMZ file is simply a compressed (zipped) version of a KML file, making it much smaller and easier to share over email or messaging apps.

How to use this tool on mobile devices?

Text editors on smartphones often corrupt KML code by saving it as a standard text file (.txt). To avoid this, simply paste your raw code into the text area above, set a file name, and hit download. This tool forces your browser to save the exact format (.kml or .kmz) securely to your device without storing your data on external servers. You can then open it directly via the Google Earth app.
